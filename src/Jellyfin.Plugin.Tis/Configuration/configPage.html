Make a library for each season's folder under Dashboard → Libraries, then add it below with the dates it should be shown. Outside those dates the library is hidden from everyone. Libraries that are not listed here are left alone.

A season does not need its own folder: leave Library on Make a library for this season, give it a name and tags, and a library holding only the tagged items is made for it.

To show a movie or show from another library in a season, give the season one or more tags below and add any of them to the item (⋮ → Edit metadata → Tags). It is linked into the season's folder at the next check, not copied.

Saving applies the dates and tags straight away. After that they are checked just after midnight and when the server starts.
